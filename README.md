# Personal Portfolio Website

**Author:** Shameel Shajaad  
**Module:** Internet Technologies (ICET Institute)  
**Language/Frameworks:** HTML, CSS, Bootstrap, JavaScript  

---

## 💡 Description

This is **My personal portfolio website**, designed to showcase projects, skills, achievements, and contact information.  
The website is fully responsive and built using **Bootstrap** for a modern layout and smooth user experience.

It highlights My journey as a **Software Engineering student**, emphasizing web development, Java projects, and digital portfolio presentation.

---

## ⚡ Features

### Responsive Layout
- Works on desktop, tablet, and mobile devices  
- Uses Bootstrap grid system for flexibility  

### Navigation
- Easy navigation with **Home, About, Projects, and Contact** pages  
- Active page highlighting in navbar  

### Hero Section
- Dynamic introduction with image and description  
- Smooth hover effects on hero image  

### Skills & Tools
- Interactive badges for skills like **Java, HTML, CSS, JavaScript, MySQL, Git, VS Code**  
- Hover effects for visual emphasis  

### Projects Showcase
- Featured **Projects section** with card layout  
- Each project includes:  
  - Project image  
  - Brief description  
  - GitHub link  
- Projects cover Java console programs, Swing GUI applications, web development projects, and more  

### About Me Section
- Cards for **Education, Skills, Interests, Hobbies**  
- Highlights key achievements  

### Achievements Timeline
- Lists milestones like **Grade 05 Scholarship, GCE O/L results, and Diploma enrollment**  
- Styled with interactive hover effects  

### Contact Page
- Provides email and a contact form  
- Encourages collaboration and project inquiries  

### Footer
- Social media links: GitHub, LinkedIn, Instagram, Facebook  
- Simple and consistent design across all pages
